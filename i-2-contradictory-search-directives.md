# I-2: Contradictory search directives in SUPERVISOR_INSTRUCTIONS prompt

## Summary

**Context:** The `SUPERVISOR_INSTRUCTIONS` prompt guides the supervisor model in the multi-agent variant through a 4-step process: gather background, clarify topic, define report structure, assemble report.

**Bug:** Step 1 says "You MUST perform ONLY ONE search" while the Additional Notes section says "Use multiple searches to build a complete picture before drawing conclusions."

**Actual vs. expected:** The model receives two incompatible constraints in the same prompt. It may follow either instruction depending on the run, leading to inconsistent research quality.

**Impact:** Non-deterministic supervisor behavior — sometimes performs one broad search, sometimes multiple targeted searches — degrading consistency of the multi-agent variant's output quality.

## Evidence

Both directives appear in `SUPERVISOR_INSTRUCTIONS` (prompts.py lines 256–307), which is given to the supervisor model as a single system prompt. The model must reconcile:

1. **Step 1:** "You MUST perform ONLY ONE search to gather comprehensive context"
2. **Additional Notes:** "Use multiple searches to build a complete picture before drawing conclusions"

These are logically incompatible — the model cannot satisfy both constraints simultaneously.

## Impact

- **Quality inconsistency:** Reports generated by the multi-agent variant vary in research depth depending on which instruction the model prioritizes
- **Unpredictable behavior:** The same topic may produce a shallow single-search plan on one run and a thorough multi-search plan on the next

## Recommendation

Resolve the contradiction by choosing one strategy.

**Decision needed:**

- Option A: **Single search for planning** — Keep the "ONLY ONE search" constraint in step 1, remove the contradictory line from Additional Notes. The supervisor does one broad search for planning; research agents handle detailed searches per section.
- Option B: **Multiple targeted searches** — Remove the "ONLY ONE search" constraint, replace with guidance like "Perform 2-3 targeted searches to build comprehensive context." Align both sections.
- Option C: **Scoped guidance** — Clarify that step 1 gets ONE search, but the overall process uses multiple. E.g., "Perform ONE search during the planning phase. Research agents will perform additional searches for each section."

### Suggested implementation (Option C)

```python
# Step 1: Change line ~265 to:
"You MUST perform ONLY ONE search during this planning phase to gather initial context."

# Additional Notes: Change line ~305 to:
"The overall research process uses multiple searches — your initial search provides planning context, while research agents perform detailed searches per section."
```
